## C. Development Instructions
1. **Inspect Previous Phase Output:**
   - Inspect the Phase 1 HTML/JS files to ensure all Phase 1 fixes are present.
2. **Implement Map Zoom & Pan Controls (`+`, `−`, `H`, `N`):**
   - Add smooth SVG `viewBox` state management on `#map` (default `viewBox="0 0 700 460"`):
     - **`+` Button (Zoom In):** Zoom in toward the center of the current viewBox (up to 3x zoom).
     - **`−` Button (Zoom Out):** Zoom out smoothly back toward `0 0 700 460`.
     - **Mouse Wheel & Drag Pan:** Allow zooming with the mouse wheel over `#map` and click-drag panning when zoomed in (while ensuring clicks on `.pin` target markers and `#H` still work).
     - **`H` Button (Center on Habitat):** Pan/zoom the `#map` `viewBox` to focus on the Habitat marker `#H` at `(165, 270)` and update `#bub` (`"Centered on Habitat Base (Octavia E. Butler Landing)."`).
     - **`N` Button (North / Reset View):** Reset `#map` `viewBox` to `0 0 700 460` and update `#bub` (`"Map aligned to Martian True North."`).
   - Update the live cursor coordinate calculation (`#co`) on `mousemove` so `LAT` and `LON` account for the active `viewBox` offset and zoom scale.
3. **Implement Interactive `Compare layers` Mode (`SYS-01`):**
   - Wire up the `Compare layers` button in `SYS-01`.
   - When toggled ON (toggle `.on` class on the button):
     - Apply a dynamic SVG `<clipPath id="cmpClip">` to the scientific overlay layers (`#L-terrain`, `#L-mineral`, `#L-steep`, `#L-heat`) controlled by mouse/touch X position across `#map`, and render a visible vertical SVG splitter line across `#map` so the user can swipe left/right to compare the `Photo (optical)` base layer against the overlays.
     - Have CAPCOM Paw announce: `"Layer comparison active! Move across the map to swipe between layers."`
   - When toggled OFF, remove the comparison clip and hide the vertical splitter line.
4. **Add Compact Mineral & Layer Legend Indicator:**
   - Render a compact, NASA-styled legend bar inside `.mapwrap` (bottom-right or top-right) showing the color keys for `#ffe1c2` (Mg-Carbonate / Delta Fan), `#5de6c4` (Clay & Olivine), and `#ff6b8b` (Steep / No-Go Zone).
