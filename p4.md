## C. Development Instructions
1. **Inspect Previous Phase Output:**
   - Confirm Phase 3's A* pathfinding and stats calculation are working.
2. **Implement Comprehensive Safety Score (`#score`, `#ring`) & `GO` / `NO-GO` Diagnostics (`#badge`, `#bub`):**
   - Calculate `sc` (0–100) from `sl` vs. `Max slope` (`#r1`), `dist` vs. `Max distance` (`#r2`), and `time / 60` (plus a 30-min reserve) vs. `Oxygen` (`#r3`):
     - If `sl > lim[0]`, `dist > lim[1]`, or `(time / 60) > lim[2]`, apply a strict penalty so `sc < 60` and set `go = false` (`NO-GO`).
     - Update `#badge` in `SAF-04` AND `#hud .badge` in `#hud` to `'GO'` (`.badge.go`) or `'NO-GO'` (`.badge.no`).
     - Update `#ring` color (`--mint` when `sc >= 75`, `--gold` when `60 <= sc < 75`, `--bad` when `sc < 60`).
     - When `NO-GO` occurs, automatically update CAPCOM Paw (`#bub`) with the specific violation reason (e.g., `"ALERT // NO-GO: Steepest slope (16 deg) exceeds suit limit (12 deg)!"` or `"ALERT // NO-GO: Walk time exceeds Oxygen reserve!"`).
3. **Implement Dynamic `Head back by` Countdown & Sol Clock (`#hb`, `#hh`):**
   - Given current EVA start time `11:05` (665 minutes from 00:00) and `Sunset` at `17:12` (1032 minutes):
     - Compute the latest safe turn-back time as `min(startTime + oxygenHours * 60 - returnWalkMinutes, sunsetTime - returnWalkMinutes)`.
     - Format as `HH:MM` and display in both `#hb` (Tablet footer) and `#hh` (HUD panel).
     - Also update the HUD Oxygen bar width (`#hud .hp` progress bar) to `Math.min(100, Math.round((lim[2] / 10) * 100)) + '%'`.
4. **Implement Emergency `Return to base` (`#rtb`) Direct Routing:**
   - When `#rtb` is clicked:
     - Run A* in `Safest` mode from the current target/waypoint directly back to Habitat `H (165, 270)`.
     - Style `#route` with high-priority coral/red stroke (`#ff6b8b`), update `#sd`, `#st`, `#ss`, and `#elev` for the return leg, and have CAPCOM Paw announce: `"Heading home. Emergency Return-to-Base route locked!"`
5. **Implement Persistent Field Notes & Sample Collection (`#modal` & `#tlist`):**
   - Maintain a `targetState` object for `A`, `B`, `C` (`{ note: '', sampled: false }`) backed by `localStorage` (`pawstro_target_state`).
   - In `openCard(i)`, populate the `<textarea>` with `targetState[i].note` and the checkbox with `targetState[i].sampled`.
   - Attach `oninput` to the `<textarea>` and `onchange` to the checkbox so edits immediately save to `targetState` and `localStorage`, re-render `#tlist` and `#pins` to show a `✓` badge on sampled targets, and trigger a CAPCOM Paw confirmation when a sample is checked.
